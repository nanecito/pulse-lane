THE LONG SIEGE — squat capture

This is not the game. It records your body doing a known list of movements, so a repetition counter can be measured against it instead of guessed at.

About ten minutes, roughly 85 squats, alternating hard and easy blocks. Every block can be skipped and you can save whatever you have done at any point. Nothing is sent anywhere — the file is written to this phone and nowhere else.
